# 有道领世 · 课程规划师工作台

纯静态工作台，部署到 GitHub Pages 即可访问与分享（全免费、无后端）。

## 包含模块
- **工作系统 / 链接**：哥伦布系统、北京基地看板等链接卡片；支持自定义添加 / 删除（存本机浏览器）
- **销售素材库**：销售流程梳理（固定首位）等 13 个文档链接；同样支持自定义增删
- **规划报告解读 / 试卷分析 / CPA**：iframe 内嵌的本地工具
- **全站搜索**：跨系统 + 素材 + 备忘录 + SOP 一次搜

## 部署
1. 进入 GitHub 仓库 → `Add file` → `Upload files`
2. 把本目录（根目录下的全部文件与子文件夹）拖入上传区 → `Commit changes`
3. `Settings` → `Pages` → Source 选 `Deploy from a branch` → `main` → `/ (root)` → Save
4. 约 1–2 分钟后访问 `https://<用户名>.github.io/<仓库名>/`

## AI 功能（报告 / 试卷）
- 首次使用在工具内粘贴你的 **豆包 (Doubao) API Key**，仅存本机浏览器，不上传服务器
- 若部署后 AI 生成失败，多为浏览器跨域 (CORS) 限制，需加轻量代理
